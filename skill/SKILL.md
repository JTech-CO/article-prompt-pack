# Article Prompt Pack

## 실행 순서

1. 사용자 요청에서 `플랫폼`을 판별한다. 명시가 없으면 `블로그`로 간주한다.
   - 블로그 / 쓰레드 / X일반 / X프리미엄 / 긱뉴스 / 전체
2. `pack.md`를 읽고 해당 플랫폼 모듈과 코어 규칙을 적용한다.
3. `분야`, `독자층`이 불명확하면 초안 내용에서 추론하되, 판단이 갈리면 사용자에게 한 번만 확인한다.
4. 분량 제약이 있는 플랫폼은 출력 직전 공백 포함 글자 수를 실측해 범위를 맞춘다.
5. 결과물 본문만 출력한다. 적용 과정이나 규격을 설명하지 않는다.

## 참조 파일

- `pack.md` — 전체 실행 규격 (이 스킬의 본체)
- `templates/input.md` — 소재 입력 템플릿

원격 사용 시에는 아래 URL을 읽는다.

```
https://raw.githubusercontent.com/JTech-CO/article-prompt-pack/main/pack.md
```

## 주의

- 초안에 없는 사실을 추가하지 않는다. 불명확한 지점은 `[확인 필요]`로 남긴다.
- 긱뉴스만 개조식이고 나머지는 존대체다. 옵션으로 `평서체`가 지정된 경우에만 예외다.
- 플랫폼이 여러 개 요청되면 사실·수치·고유명사를 전 결과물에서 동일하게 유지한다.
