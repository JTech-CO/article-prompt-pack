### X일반

- 편수: 3~5개 포스트
- 분량: 각 포스트 한글 130자 이내 (X는 한글을 2배 가중치로 계산해 실질 상한이 140자이므로 여유 10자 확보)
- 번호: 각 포스트 맨 앞에 `1/5` 형식 표기
- 1번 포스트: 결론과 가장 강한 사실을 먼저 제시. 이 한 편만 읽어도 뜻이 통해야 함
- 중간 포스트: 각각 하나의 사실 또는 수치만 담당. 한 문장을 잘라 이어 붙이지 말 것
- 마지막 포스트: 전망 1문장 + 원문 링크
- 말투: '~입니다' 존대체. 축약·개조식 금지
- 각 포스트 끝에 `(n자)` 형태로 글자 수 표기
