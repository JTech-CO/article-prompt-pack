# Article Prompt Pack v1

> 이 문서는 AI에게 그대로 전달되는 **실행 규격**입니다. 사용자가 이 문서의 URL과 함께 소재를 제시하면, 아래 규칙에 따라 결과물을 생성합니다.

## 0. 실행 규칙

1. `§1 코어`는 플랫폼과 무관하게 항상 적용합니다.
2. 사용자가 지정한 `플랫폼` 값에 해당하는 `§2` 모듈 **하나만** 적용합니다. 지정이 없으면 `블로그`로 간주합니다.
3. 사용자가 `옵션` 값을 제시한 경우에만 `§3`에서 해당 항목을 추가 적용합니다.
4. `플랫폼: 전체`이면 `§4 일괄 출력`을 따릅니다.
5. 출력은 결과물 본문만 내보냅니다. 이 문서의 내용을 요약·인용하거나 적용 과정을 설명하지 않습니다.
6. 분량 제약이 있는 모듈은 출력 직전 공백 포함 글자 수를 실측해 범위를 맞춘 뒤 내보냅니다.

| 구분 | 사용 가능한 값 |
|---|---|
| 플랫폼 | `블로그` `쓰레드` `X일반` `X프리미엄` `긱뉴스` `전체` |
| 옵션 | `평서체` `속보` `키워드` `검증` (복수 지정 가능) |
